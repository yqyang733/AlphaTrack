# 两种策略回测计算复核（2026-11-11）

复核对象为排名版与随机版（seed 42），各自从 2010、2015、2020、2025 年初空仓开始的四个独立窗口，共 8 次回测，截止 2026-11-06。覆盖 Fundb、Fundc、Fundd、Fundf_1、Fundg 全部 63 只基金。以已经核验的 QLab 曲线和规则为参照，重点检查 AlphaTrack 的输入转换、交易与分红记账、现金流、收益指标及图表。

## 核算方法

1. 输入：把归档的单位净值、除息日每份现金分红和份额折算逐项与标准化 CSV 对比。使用独立 QLab 源码和完整分红文件重算复权曲线，与 AlphaTrack 输入曲线逐点比较。
2. 交易账本：不调用生产引擎，以 40 位 Decimal 和归一化份额重新执行上一净值观察日的信号。分红只属于事件前持有的份额，按除息日净值再投资；新买份额不获得当日分红，折算不改变成本。
3. 盈亏：独立累积“旧份额价格变化＋分红权益”，再与“期末资产＋累计取出－累计投入”交叉核对。年度盈亏另按年初、年末资产和当年现金流核对。
4. 组合净值：通过按当前价格发行或赎回组合份额重建单位净值，检查追加本金与卖出提款不会变成收益。异步净值只向后沿用已有估值；投入和提款属于当天事件，不能向后填充。
5. XIRR：使用投入为负、提款与期末资产为正的实际日期现金流独立求根，并检查报表中收益率代入后的净现值残差。类别账户先合并现金流再求 XIRR，不平均各基金的 XIRR。
6. 图表：解析实际 HTML 中 Plotly 的日期和数值数组，核对累计盈亏、每日盈亏、单位净值、回撤、资金曲线、年度柱状图及分类明细。
7. 信号时序：只输入截至四个历史日期的数据重新计算全部基金指标，与完整历史的对应前缀逐列对比；独立重算 Fundb/c 的横截面评分、排名和随机顺序，核对已有信号的动作、金额及新净值门禁。

## 已完成的全量结果

- 173,282 条原始单位净值逐条匹配；全部 63 条基金复权曲线与独立 QLab 计算一致，最大绝对误差 5.55×10⁻¹⁷。
- 597 条原始事件包含 563 条现金分红和 34 条折算；595 条映射至净值记录。其余两条为原有 000931 缺少除息日净值的已知情况，两个系统保持相同处理。
- 8 个窗口共 903,160 条基金日账本、273,524 条执行或拒绝订单和 272,808 条 FIFO 分块完成独立复算；共 23,164,332 项比较，0 失败。已检查真实分红日买入、分红日卖出、折算及期末待成交信号。未发现重复计分红、当日信号当日成交或将追加本金计入盈亏的问题。
- 8 个组合、40 个分类账户及 10 份 HTML 的收益与图表数据通过独立复核，共 5,296 项检查，0 失败。年度金额覆盖组合 76 条、分类 380 条。最大金额差小于 0.00001 元，来自导出 CSV 的有效位数；此前展示到分或万元的数字不受影响。
- 信号前视检查覆盖 2017-12-29、2017-12-30、2021-01-22、2025-12-31。全部 63 基金共 210 个非空历史前缀、346,179 行逐列一致，指标误差为 0；42 个基金/日期组合尚无历史数据。两策略的 Fundb/c 共 16 组、194 条当日信号一致，评分误差最大 4.24×10⁻¹²。特殊周末日期也保留了陈旧候选占名额、仅有新净值者发单的原规则。

发现并修正两处报告文字：随机版沿用了“按排名买入”的默认说明；TWR 卡片误写“按完整评价时间年化”，实际按首次投入日期起年化。计算公式和策略数值无需调整。

8 份单窗口 HTML 已重新生成并再次通过图表审计；重渲染前后 116 份数值产物的 SHA256 完全相同。完整回归为 108 项测试及 32 项子测试通过。

## 结论的范围

结论适用于本次零手续费、下一条净值观察记录成交、按需追加资金、卖出净回款立即取出的理论回测。净值实际公布时间、交易确认及到账延迟等未建模；这里的“下一条净值”不等于已校验交易所交易日。当前基金名单的历史回放也不代表当时已知的基金池。

QLab 原有的 000931 两次分红缺净值和 000037 历史断档保持原状。此次没有移动分红日期、补造净值或改变原有策略规则。XIRR 多次现金流变号时，有限数值扫描只能确认已找到的根，不能证明全局唯一性。

信号无前视的实证检查覆盖上述四个历史截止点，结合原代码的向后滚动/截至当日横截面逻辑与既有无前视测试，不声称穷举所有可能的数据与日期。
