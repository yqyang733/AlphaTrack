# AlphaTrack

可复现的回测软件原型：数据 → 策略 → 下一净值日成交 → 现金与持仓记账 → 指标 → 离线 Plotly HTML。

首个 Demo 使用 **110020 易方达沪深300ETF联接A + QLab Fundd 宽基规则**。从成立日开始逐日评估，**资金无限、按需补足、卖出款留在账户再利用**。不是在成立当天强制买入，也不是每天固定投入。

## 快速运行

Python 3.11+：

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e '.[test]'
python -m alphatrack --config configs/110020_fundd.json
pytest -q
```

直接打开 `reports/110020_fundd.html`。HTML 包含 Plotly 本身，无须联网或启动服务器。随附 `.daily.csv`、`.trades.csv`、`.summary.json` 可逐笔复核。GitHub 文件预览不会执行 HTML，请下载后在浏览器打开。

自定义日期/数据/输出：

```bash
python -m alphatrack --config configs/110020_fundd.json --start 2015-01-01 --end 2025-12-31 --output reports/custom.html
python scripts/update_eastmoney.py --code 110020 --output data/110020.csv
```

修改 JSON 即可改变基数、买入阈值/倍数、卖出梯度、交易费用、无风险利率、资金模式。日期外的历史只用于计算历史位置，不会回放日期外的持仓或卖出状态。所有 JSON 中的相对路径以配置文件目录为基准，命令行路径以工作目录为基准。未给日期时，使用数据文件的完整覆盖期；不自动把未来日期补成净值。

## Fundd 规则

来源 `https://github.com/yqyang733/QLab` 的 `core/calculator.py`、`core/analyzer.py`、`trading/config.py`、`trading/engine.py`、`trading/service.py` 和基金分类表。具体审计版本写入数据元信息。

1. 先形成分红再投资总收益指数，再计算近5年、近10年、成立以来的位置 `(当前值 - 最低值) / (最高值 - 最低值)`，取三者最小值 `x`。这不是统计百分位排名。滚动窗口按日历年，含当天，只用当时已有历史；不足2条时不交易，平盘窗口位置为50%。
2. 110020 属于宽基，基数50元：`10%≤x≤20%` 买50；`5%≤x<10%` 买100；`0<x<5%` 买150；`x≤0%` 买200。每个符合条件的净值观察日都会产生买入信号。
3. 卖出阈值由50%至100%等距分为50档。各档对应本轮初始份额的 `0.9×i/(1+…+50)`，按当前剩余份额比例依次执行，全部走完累计卖90%，余10%。不是每档等额，也不是每档卖当前仓位的1/50。
4. 一天跨过多档则合并执行；同一轮每档仅一次；再次进入买入区间重置卖出档位。买入优先。遵循 QLab 信号状态，即使资金不足也按信号重置/推进。
5. QLab 的“结合持有收益判断”是文字备注，没有正收益才卖出的硬条件；此处不擅自添加。

## 成交和资金假设

- 当日净值公布后计算信号，在**下一条可用净值**成交，消除同净值信号与成交的前视偏差。最后一日的信号标为 `PENDING_END_OF_DATA`，不虚构成交。
- 成立日2009-08-26只有1条记录，因此HOLD；成立初期净值不是每日披露，下一观察日可能相隔数天。
- 默认本金0，买入金额不足时注入差额；卖出现金继续保留，可复用。资产 = 现金 + 份额 × 原始单位净值；追加资金不构成收益。支持另选 `fixed` 固定本金，现金不足部分成交，不透支。
- 默认费用0、现金利息0、无风险利率0。申购/赎回费率可分别设置（小数，如0.0015）。申购份额按 `申购总额/(1+费率)/净值` 计算；卖出费用按成交总额×赎回费率计算。
- 允许小数份额、当日入账；不模拟历史申赎开放状态、成立封闭期、限额、到账延迟、税、最低收费和持有期阶梯赎回费。**这是理论净值成交 Demo，不能视为完全可执行的历史实盘。** 管理费等已体现在真实基金净值中，不重复扣。
- 默认分红再投资；拆分先处理、随后按拆分后每份分红再投资；现金分红的再投资不增加外部本金或原始持仓成本。本 Demo 数据未发现分红/拆分事件。其他基金必须提供正确的公司行为数据，不能把累计净值直接当复权交易价格。
- 期末按净值估值，不强制清仓；所以没有期末未执行赎回费用。

## 收益与风险口径

| 指标 | 口径 |
|---|---|
| 净投入本金 | 外部入金累计额，卖出款循环利用不重复计入 |
| 每日盈亏 | 当日总资产 − 前日总资产 − 当日外部入金 |
| 累计总盈亏 | 期末总资产 − 净投入本金，也等于每日盈亏之和 |
| 总盈利 / 累计本金 | 累计总盈亏 / 净投入本金；不是年化收益 |
| 时间加权收益 TWR | 将入金前盯市收益与入金后交易费用收益分段连乘；无交易费时等价于 `每日盈亏/前日资产`；第一笔入金日仅计费用影响 |
| CAGR | TWR净值按首次入金至期末实际天数/365.25复合年化；不是简单总收益/年数 |
| XIRR | 每笔外部入金为负现金流，期末总资产为正现金流，按实际日期求年化；更接近投资者体验 |
| 当前持仓收益率 | 当前未实现盈亏 / 当前持仓的剩余历史成本；不含已卖出部分 |
| 已实现/未实现盈亏 | 按平均成本分摊；含交易费，保留红利再投资收益 |
| 年化波动率 / 夏普 | 已入金后观察日收益的样本标准差×√252；夏普为平均超额日收益/标准差×√252 |
| Sortino | 超额日收益负值平方均值的平方根作下行偏差，所有已入金观察日作分母 |
| 最大回撤 / Calmar | TWR净值相对历史峰值最大跌幅；CAGR/最大回撤绝对值 |
| 回撤持续时间 | 净值未创新高的最长自然日时长，包含期末未恢复区间 |
| 正收益日占比 | 已入金的净值观察日中日收益>0比例；不是交易胜率 |

“每日”指净值观察日，不伪造周末净值。早期稀疏披露意味着252观察日年化波动率和夏普只是一种统一近似；CAGR/XIRR使用实际日期。收益图包含回测起点买入持有参考，参考的资金投入节奏与策略不同，不直接等同于同现金流超额收益。持有现金会降低风险暴露，属于策略账户收益的一部分。

## 架构和扩展

- `data.py`：CSV数据适配与验证；`date,nav`必需，`dividend`每份现金分红、`split`份额倍数可选。
- `strategies/`：注册表及策略协议。`prepare(frame)`只计算因果特征，`decide(row)`返回 BUY/SELL/HOLD、金额或比例、原因和档位。每次回测创建新实例。
- `engine.py`：策略无关的单资产事件循环、资金流、成交、平均成本账本。
- `metrics.py`：与策略解耦的资金流调整、年化和风险计算。
- `report.py`：不依赖策略内部结构的Plotly可视化及逐笔交易查询。
- `cli.py`：JSON配置与输出编排。

未来新增策略只需注册工厂；新增数据源输出统一CSV；新增费用模型/多资产组合可分别替换执行与组合层。当前版本**只实现单资产日频/净值观察频率回测**，尚不支持多资产撮合、任意资金提取、杠杆/做空、逐笔行情或浏览器内实时重算；没有把通用软件愿景误写成已实现功能。

策略插件须自行遵守因果性，框架不能自动阻止任意插件偷看未来。内置 Fundd 有前缀不变性测试。源数据及策略快照固定，附摘要哈希便于复现。
